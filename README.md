# منظومة تحليل إنستاجرام (PHP)

منظومة PHP متكاملة لثلاث مهام على إنستاجرام، لكل واحدة **صفحة ويب** و**نقطة API** بصيغة JSON:

| الأداة | الصفحة | نقطة الـ API |
|---|---|---|
| التحقق من توفّر اسم مستخدم | `/username` | `GET /api/username/check` |
| تحليل حساب (متابعون، لايكات، تعليقات، ريبوست) | `/analyze` | `GET /api/account/analyze` |
| قياس سلوك حساب وردوده | `/behavior` | `GET /api/account/behavior` |
| حالة المنظومة والمزوّدين | — | `GET /api/health` |

بدون أي اعتمادات خارجية: PHP 8.1+ مع `curl` و`json` و`mbstring` فقط.

---

## التشغيل السريع

```bash
git clone https://github.com/Buhhotto/instagram-Cheker.git
cd instagram-Cheker
cp .env.example .env          # اختياري: للتشغيل ببيانات حقيقية
php -S localhost:8000 -t public
```

ثم افتح <http://localhost:8000>.

المنظومة تعمل فورًا بلا مفاتيح عبر **وضع التجربة** (بيانات مُصطنعة موسومة بوضوح).
لتشغيل الاختبارات:

```bash
php tests/run.php
```

## مصادر البيانات

تُجرَّب المصادر بالترتيب، وأول مصدر يُرجع نتيجة صالحة هو المستخدَم، ويُذكر اسمه في حقل `source` من كل استجابة.

### 1) Graph API الرسمي (الأدق)

يحتاج حساب إنستاجرام **أعمال أو منشئ محتوى** مرتبطًا بصفحة فيسبوك، وتوكن من [Meta for Developers](https://developers.facebook.com).

```dotenv
IG_ACCESS_TOKEN=EAAG...
IG_USER_ID=178414...
IG_OWNER_USERNAME=my_account
```

- بيانات أي حساب أعمال عام عبر `business_discovery`: المتابعون، المنشورات، اللايكات، التعليقات.
- **التعليقات والردود** متاحة لحساب التوكن نفسه فقط (`IG_OWNER_USERNAME`) — قيد من إنستاجرام لا يمكن تجاوزه.

### 2) الواجهة العامة (بدون توكن)

`IG_PUBLIC_WEB_ENABLED=true` — تُستخدم أساسًا للتحقق من توفّر الأسماء. قد يحدّ إنستاجرام الطلبات أو يطلب تسجيل دخول،
وعندها تُرجع المنظومة `unknown` بدل تخمين نتيجة غير مؤكدة، وتُسجّل تحذيرًا يوضّح سبب تخطّي المصدر.

### 3) وضع التجربة

`IG_DEMO_ENABLED=true` — بيانات مُصطنعة **حتمية** (نفس الاسم ⇒ نفس النتيجة) لتشغيل كل الشاشات بدون مفاتيح.
كل نتيجة مصدرها هذا الوضع تُوسم بـ `source: "demo"`، وتُخفَّض ثقتها، ويظهر تحذير صريح في الواجهة والـ API.
**اجعله `false` في الإنتاج.**

## أمثلة على الـ API

```bash
curl "http://localhost:8000/api/username/check?username=nasa"
curl "http://localhost:8000/api/account/analyze?username=nasa&limit=25"
curl "http://localhost:8000/api/account/behavior?username=nasa&limit=25"
```

كل الاستجابات بالشكل `{"ok": true, "data": {...}}` أو `{"ok": false, "error": "..."}`
برموز HTTP مناسبة: `422` مدخل غير صالح، `404` حساب غير موجود، `429` تجاوز حدّ الطلبات، `503` لا يوجد مزوّد مهيّأ.

### ماذا تُرجع كل نقطة؟

**`/api/username/check`** — فحص القواعد (الطول، الحروف المسموحة، النقاط، الأسماء المحجوزة)، ثم الوجود الفعلي،
مع حالة نهائية: `available` / `taken` / `reserved` / `invalid` / `unknown`، ودرجة ثقة، وبدائل مقترحة مع فحص توفّر أوائلها.

**`/api/account/analyze`** — الملف الشخصي، معدّل التفاعل مقارنًا بمعايير مرجعية، إحصاءات اللايكات والتعليقات
(متوسط، وسيط، انحراف معياري، ثبات الأداء)، توزيع أنواع المحتوى وأداء كل نوع، إيقاع النشر، أفضل المنشورات،
أكثر الوسوم والإشارات، مؤشرات جودة الجمهور، وملخّص **إعادة النشر**.

**`/api/account/behavior`** — خريطة نشاط أسبوعية (7×24)، أفضل أوقات وأيام النشر، انتظام الإيقاع،
سلوك الكتابة (الطول، الرموز التعبيرية، الأسئلة، دعوات التفاعل، النبرة)، **سلوك الردود**
(نسبة الرد، سرعته، أسلوبه، نبرته، نبرة الجمهور، أكثر المتفاعلين)، وستّ درجات سلوكية مع مؤشر عام،
ونمط سلوكي (Archetype) وتوصيات مبنية على القياس.

## كيف تُقاس الأمور غير المتاحة مباشرة؟

إنستاجرام لا يوفّر كل ما قد يُطلب، والمنظومة تُصرّح بذلك بدل ادّعاء اليقين:

- **إعادة النشر (Repost):** لا يوجد حقل رسمي لها. تُكشف بمؤشرات نصية مرجّحة (كلمات دالة مثل `repost`/`منقول`/`credit`،
  وسوم إعادة النشر، نسب المصدر في بداية التسمية)، وتُرجع **درجة ثقة** لكل منشور مع المؤشرات التي بُنيت عليها.
- **النبرة:** معجم عربي/إنجليزي مع معالجة النفي — كافٍ لاتجاه عام، وليس بديلًا عن نموذج لغوي.
- **الردود:** تُقرأ فقط لحساب تملك توكنه، وإلا تُعرض رسالة تشرح القيد بدل تصفير النتيجة بصمت.
- **المتابعون:** لا تتيح أي واجهة رسمية قائمة المتابعين، لذلك تُقاس جودة الجمهور بمؤشرات غير مباشرة
  (لايكات لكل متابع، نسبة المتابِعين إلى المتابَعين، تذبذب التفاعل).

توفّر «متاح» لاسم مستخدم تعني أن إنستاجرام لا يعرض حسابًا به وقت الفحص، ولا تضمن قبوله عند التسجيل.

## البنية

```
public/            نقطة الدخول (index.php) وملفات الواجهة
  assets/app.css   نمط داكن متجاوب يدعم RTL
src/
  Autoloader.php   محمّل PSR-4 داخلي (يعمل بدون Composer)
  Container.php    حاوية الخدمات
  Support/         الإعدادات، البيئة، النصوص، الإحصاء، العشوائية الحتمية
  Cache/           تخزين مؤقت على الملفات
  Http/            الطلب، الاستجابة، الموجّه، عميل cURL، حدّ الطلبات، المتحكمات
  Instagram/
    Contracts/     عقد مزوّدي البيانات
    Providers/     Graph API، الواجهة العامة، وضع التجربة
    DTO/           Profile، Media، Comment
    Analysis/      كشف إعادة النشر، تحليل النبرة
    ProviderChain.php  تسلسل المصادر وتسجيل التحذيرات
    UsernameChecker.php / AccountAnalyzer.php / BehaviorAnalyzer.php
  View/            محرّك قوالب بسيط
views/             القوالب (layout، pages، partials)
config/config.php  الإعدادات
tests/run.php      الاختبارات (بدون شبكة)
deploy/            نموذج إعداد nginx
```

## الحماية والحدود

- **حدّ الطلبات**: 30 طلبًا/دقيقة لكل عميل افتراضيًا (`RATE_LIMIT_MAX`).
- **تخزين مؤقت**: 15 دقيقة افتراضيًا لتقليل الضغط على واجهات إنستاجرام (`CACHE_TTL`).
- **هروب كامل للمخرجات** في كل القوالب، ولا تُنفَّذ أي بيانات واردة.
- في الإنتاج اجعل جذر الخادم مجلد `public` فقط (انظر `deploy/nginx.conf.example`)، واضبط `APP_DEBUG=false`.
